# Инструкция по наполнению сайта MB Engine

## 📋 Общая информация

Сайт построен на **Express.js** с использованием шаблонов **EJS** и стилизации **Tailwind CSS**. Все данные хранятся в JSON-файлах.

---

## 🗂️ Структура проекта

```
mb-engine-service/
├── data/              # Данные сайта (JSON)
│   ├── engines.json   # Информация о двигателях
│   ├── services.json  # Услуги и цены
│   └── portfolio.json # Портфолио работ
├── views/             # Шаблоны страниц (EJS)
│   ├── layout.ejs     # Общий шаблон (header, footer)
│   ├── index.ejs      # Главная страница
│   ├── services.ejs   # Страница услуг
│   ├── portfolio.ejs  # Портфолио
│   └── contacts.ejs   # Контакты
├── public/            # Статические файлы
│   └── js/
│       └── main.js    # JavaScript код
└── app.js             # Основной файл приложения
```

## 📝 Редактирование данных

### 1. Услуги (data/services.json)

**Что редактировать:**
- `name` — название услуги
- `description` — подробное описание
- `shortDescription` — краткое описание для карточек
- `price` — цена услуги
- `duration` — время выполнения
- `icon` — иконка Font Awesome (см. список ниже)
- `forEngines` — массив ID двигателей, для которых подходит услуга

**Как добавить новую услугу:**

```json
{
  "id": "uniquename",
  "name": "Название услуги",
  "description": "Подробное описание...",
  "shortDescription": "Краткое описание",
  "price": "от XXX руб",
  "duration": "X часов/дней",
  "icon": "fa-icon-name",
  "forEngines": ["m272", "m273"]
}
```

**Список иконок Font Awesome:**
- `fa-stethoscope` — диагностика
- `fa-cogs` — ремонт
- `fa-microchip` — электроника
- `fa-sync-alt` — замена ГРМ
- `fa-oil-can` — масло/турбина
- `fa-wind` — турбина
- `fa-tools` — инструменты
- `fa-car` — автомобиль

---

### 2. Двигатели (data/engines.json)

**Что редактировать:**
- `name` — название двигателя (M272, M273 и т.д.)
- `type` — тип (бензиновый V6/V8 или дизельный V6/V8)
- `years` — годы выпуска
- `description` — описание совместимых моделей

**Как добавить новый двигатель:**

```json
{
  "id": "enginecode",
  "name": "Название двигателя",
  "type": "бензиновый V6",
  "years": "2010-2015",
  "description": "Описание двигателя и совместимых моделей"
}
```

---

### 3. Портфолио (data/portfolio.json)

**Что редактировать:**
- `title` — название работы
- `description` — описание выполненной работы
- `engineId` — ID двигателя (должен совпадать с engines.json)
- `type` — тип: `"photo"` (фото) или `"video"` (видео)
- `images` — массив путей к изображениям (относительно `/public/images/`)
- `videoUrl` — ссылка на YouTube видео (для type: "video")
- `date` — дата выполнения работы

**Как добавить новую работу:**

```json
{
  "id": "unique-work-id",
  "title": "Название работы",
  "description": "Описание выполненной работы...",
  "engineId": "m272",
  "type": "photo",
  "images": ["/images/work-1.jpg", "/images/work-2.jpg"],
  "videoUrl": null,
  "date": "2024-03-15"
}
```

**Путь к изображениям:**
Изображения должны лежать в папке `public/images/` и указываться как `/images/work-name.jpg`.

## 🖼️ Добавление изображений

### 1. Создание папки для изображений

```bash
mkdir public/images
```

### 2. Загрузка изображений

Разместите изображения в папке `public/images/`:

```
public/images/
├── work-m272-1.jpg
├── work-m272-2.jpg
├── hero-bg.jpg          # Фоновое изображение для главной
└── service-icon-1.png   # Иконки услуг (опционально)
```

### 3. Использование изображений в шаблонах

**В layout.ejs (header/footer):**
Изображения используются только через иконки Font Awesome. Для замены логотипа отредактируйте строку 51-52:

```html
<div class="text-2xl font-bold">
    <img src="/images/logo.png" alt="MB Engine" class="h-10">
</div>
```

**В index.ejs (hero section):**
Для замены фона главного баннера отредактируйте строку 2:

```html
<section class="relative bg-[url('/images/hero-bg.jpg')] bg-cover bg-center py-20 md:py-32">
```

**В portfolio.ejs:**
Изображения подтягиваются автоматически из `portfolio.json` в массиве `images`.

## 🎨 Редактирование стилей (layout.ejs)

### 1. Цветовая палитра

Все цвета определены в блоке `<style>` (строки 13-43):

| Класс | Значение | Для чего |
|-------|----------|----------|
| `.gold-accent` | `#b8860b` | Золотой акцентный цвет |
| `.gold-border` | `#b8860b` | Золотая граница |
| `.gold-bg` | `#b8860b` | Золотой фон кнопок |

**Как изменить основной золотой цвет:**

```css
.gold-accent { color: #ВАШ_ЦВЕТ; }  /* для текста */
.gold-border { border-color: #ВАШ_ЦВЕТ; }  /* для границ */
.gold-bg { background-color: #ВАШ_ЦВЕТ; }  /* для фона */
```

### 2. Изменение цвета текста на Hero Section

Если вы добавили изображение на главный баннер, текст может сливаться с фоном. Для решения этой проблемы добавьте класс `hero-section` к секции и используйте встроенные стили:

**Шаг 1:** Добавьте класс `hero-section` в HTML (строка 2 index.ejs):

```html
<section class="relative hero-section bg-[url('/images/hero-bg.jpg')] bg-cover bg-center py-20 md:py-32">
```

**Шаг 2:** В layout.ejs добавьте стили для Hero Section (строки 13-43):

```css
.hero-section {
    position: relative;
}
.hero-section::before {
    content: '';
    position: absolute;
    top: 0;
    left: 0;
    right: 0;
    bottom: 0;
    background: rgba(0, 0, 0, 0.6); /* Затемнение фона */
    z-index: 1;
}
.hero-section > * {
    position: relative;
    z-index: 2;
    color: #ffffff !important; /* Белый цвет текста */
}
```

**Шаг 3:** Измените цвет текста в `.gold-accent` (строка 21):

```css
.gold-accent {
    color: #ffffff; /* Белый цвет вместо золотого */
}
```

### 3. Шрифты

Google Fonts подключен в строке 11-12. Можно добавить другие шрифты:

```html
<link href="https://fonts.googleapis.com/css2?family=Montserrat:wght@300;400;500;600;700;800&display=swap" rel="stylesheet">
<link href="https://fonts.googleapis.com/css2?family=Roboto:wght@300;400;500;700&display=swap" rel="stylesheet">
```

### 3. Анимации

Класс `.card-hover` (строки 33-36) добавляет эффект при наведении:

```css
.card-hover:hover {
    transform: translateY(-5px);
    transition: all 0.3s ease;
    box-shadow: 0 10px 25px -5px rgba(0, 0, 0, 0.5);
}
```

## 🚀 Быстрый старт по редактированию

### Чтобы изменить цену услуги:
1. Откройте `data/services.json`
2. Найдите нужный ID услуги
3. Измените поле `price`
4. Сохраните файл

### Чтобы добавить новую работу в портфолио:
1. Откройте `data/portfolio.json`
2. Скопируйте структуру существующей работы
3. Измените `id`, `title`, `description`, `images`
4. Добавьте новые поля при необходимости
5. Сохраните файл

### Чтобы добавить изображение:
1. Положите файл в `public/images/`
2. Отредактируйте JSON-файл и укажите путь `/images/имя_файла.jpg`
